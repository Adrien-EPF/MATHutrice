# `course-2026` becomes the default branch

For the 2026–27 *Complex Web Services* course, about twenty students fork MATHutrice from the default branch, so `course-2026` becomes the repository's default branch. Forks start from it, and course-related PRs target it (including the **connexion de développement**, #18, and the fork preparation, #19), so that course-specific code stays out of `main`.
