# `course-2026` devient la branche par défaut

Pour le cours *Complex Web Services* 2026–27, une vingtaine d'étudiants forkent MATHutrice depuis la branche par défaut : `course-2026` devient donc la branche par défaut du dépôt. C'est d'elle que partent les forks et vers elle que visent les PR liées au cours (dont la connexion de développement, #18, et la préparation du fork, #19), pour ne pas mêler à `main` du code propre au cours.
